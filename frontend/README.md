# Project Management Dashboard — Frontend

## Overview
This project is the frontend of a team-based Project Management System, developed using React and Vite.

## Features
- Dashboard with project summary cards
- Sidebar navigation
- Recent projects with progress indicators
- My Tasks section
- Calendar navigation
- Gradient backgrounds, animations, and visual effects

## Technologies Used
- React
- JavaScript (JSX)
- CSS
- Vite

## Setup Instructions

### 1. Navigate to the frontend folder
```bash
cd frontend
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```

Open the local URL shown in the terminal to view the dashboard.
